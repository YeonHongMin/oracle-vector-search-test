# scripts — Example excerpts from the book series

Example code blocks extracted chapter by chapter from **『Oracle AI Database 26ai Vector Search』** (3 volumes + omnibus, Korean technical book series by Min Yeonhong).

- [`kr/`](kr/) — faithful excerpts from the published Korean book (Korean comments)
- [`en/`](en/) — English-commented edition. **Code lines are identical to `kr/`**; only comments and user-facing sample strings (error messages, demo binds, COMMENT ON text) are translated. Korean data literals that the examples functionally depend on (Korean corpus queries, `KOREAN_MORPH_LEXER` samples, region filters) are intentionally preserved so the demos still return the documented results.

> **Runnability** — these are book excerpts. Some assume bind variables (`:qvec`), POC helper objects (`poc_*`, `cct_*`, `hvi_*`), or pre-loaded public-data tables (dataset CSVs live in [`../KO/`](../KO/) and [`../EN/`](../EN/)). Follow the corresponding book section first for a full reproduction.

> **Python note** — the three Python excerpts compile clean (`ast`-verified). `01-pathlib.py` requires OML4Py (`oml`) on the database-server Python. `01-array.py` requires `oracledb` and reads credentials from `ORACLE_USER` / `ORACLE_PASSWORD` / `ORACLE_DSN` environment variables — nothing is hardcoded. `04-get_json.py` is a fragment of the collection flow; its `BASE` / `get_json` definitions live in the surrounding script shown in the book.

> **Privacy** — verified 0 occurrences of the author's home DDNS, personal account name, or public IP across both trees and the full git history. Hosts are shown as the `<dgx spark>` placeholder; `192.168.0.x` (private range) and `rac1`/`rac2` hostnames are generic values.
